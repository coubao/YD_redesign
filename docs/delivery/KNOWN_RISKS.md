# 已知风险与待确认事项

1. 官网原有管理路由不具备账号鉴权。交付数据使用独立数据库且只经 `/delivery` 权限层访问，但同域旧后台风险仍存在，应另开安全整改工作，不在本次功能开发中改动预约逻辑。
2. 临时 PostgreSQL 的 CI 空库迁移已通过；独立 PostgreSQL staging、HTTPS 代理行为、PostgreSQL 备份恢复和微信浏览器实机尚未验收。上线前必须补齐，不应把 CI 临时库等同于生产验证。
3. 原始文件没有家长账号或授权关系，也没有可直接公开给家长的统一说明。所有家长账号、项目授权和任务公开须由管理员人工确认。
4. V1.1 的模板可能含个案内容，首次导入统一设为待审核。分类完成前，新项目不会自动生成模板任务。
5. V0.2 HTML 是浏览器本地存储快照。若团队在该文件中另做过未同步至 V1.1 的本地修改，仅凭文件内 `SEED` 无法发现；需人工提供导出的最新备份再比较。
6. 当前附件仅建元信息表，未提供上传与下载界面；如以后需要文件协作，应先确定私有对象存储、病毒扫描、权限及保留策略。
7. 通用模板及已导入任务的“下一步动作”等原始字段保存在私有数据库中，但尚未全部设计为可编辑字段；本轮工作台覆盖实际使用最频繁的状态、截止日期、负责人、公开说明和阻塞原因。
8. SOP 文本未提供，无法核对其微信维护细则。
