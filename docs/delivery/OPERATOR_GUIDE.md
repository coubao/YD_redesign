# 申请交付系统使用说明

## 员工日常更新

登录 `/delivery/login`，在项目列表中打开负责的项目。任务右侧「完成」可一键更新；其他状态、截止日期、负责人、阻塞原因和家长展示说明在「调整状态与展示」中修改。相同值重复提交不会新增任务变更记录。逾期任务会显示「已逾期」。任务与里程碑分开显示。

默认任务仅内部可见。需要让家长看到时，先检查任务名称及「家长展示说明」，再勾选「家长可见」。内部备注、阻塞原因原文与负责人讨论不会显示在家长端。若延期需要解释，请在家长展示说明中写明可公开的原因。

「微信文字辅助匹配」只识别当前项目中的任务编号（例如 `US-01`），返回候选任务及状态建议；点击「确认更新」后才写入数据库。它不读取微信聊天、不向微信发送消息，也不保存粘贴的原文。右上「家长摘要」从已公开任务自动生成文本，可人工检查后复制给家长。

## 家长查看

管理员先在「账号与授权」创建家长账号并授权学生。家长登录同一 `/delivery/login` 后，只能看到获授权项目与已公开的任务、节点；页面展示当前阶段、完成事项、推进事项、待配合事项、下一步及阻塞说明。没有记录的部分显示「待确认」。

## 模板与新项目

导入的模板全部待审核。管理员在「任务模板」逐项归类：标准通用、条件触发、个案专属或待审核。条件触发必须填写触发条件。新建项目时仅复制已审核的标准通用任务；特殊任务由员工在项目中追加。导入的历史项目需由管理员指定项目负责人，之后员工才能访问。

## 数据导入步骤（仅本地/隔离 staging）

1. 在独立数据库完成迁移与管理员初始化。确认 `DELIVERY_ENV` 不是 `production`。
2. 只读预览：`python -m flask --app app delivery-preview 'V1.1.xlsx' '个案旧表.xlsx' 'V0.2.html'`。核对数量、重叠编号及冲突。输出不含学生姓名。
3. 只选择 V1.1 主表，按预览输出的完整 SHA-256 人工确认后运行：`python -m flask --app app delivery-import-master '/private/V1.1.xlsx' --sha256 <digest>`。导入目标必须没有既有学生或模板记录。
4. 核对数据库中的学生、任务和模板数量；检查部分任务与阶段，再审核模板、指定负责人、设置家长可见性和家长账号。
5. 若导入后尚无任务编辑、家长授权或新增节点，可运行 `python -m flask --app app delivery-rollback-import <batch-id>`。有后续操作时工具拒绝自动回滚，须先人工评估。

真实 Excel、V0.2 HTML、预览报告中的敏感扩展数据及备份文件不得加入 Git。导入的原始行内容只存于独立私有数据库。
